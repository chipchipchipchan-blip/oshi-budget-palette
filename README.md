# Oshi Budget Palette

【アプリの目的】

推し活（ファン活動）に特化した、おしゃれで可愛いお金管理（家計簿）アプリを作りたいです。プログラミングの知識がない初心者なので、デザインから機能まで自動で構築してください。

【デザインの希望】

・「推し活」のテンションが上がる、韓国風のくすみパステルカラー（淡いピンク、パープル、ミントなど）を基調とした、清潔感があってお洒落なデザインにしてください。

・全体的に少し丸みのあるボタンやカードを使い、触っていて気持ちいいUIにしてください。

・アイコンを効果的に使い、数字ばかりで堅苦しくならないようにしてください。

【メイン機能】

1. ダッシュボード（ホーム画面）

　・今月使った「合計金額」を大きくお洒落に表示。

　・「推し別」の支出割合がひと目でわかる可愛い円グラフ。

　・「グッズ」「チケット」「遠征費」「FC・月額」などのカテゴリ別グラフ。

2. 支出の登録機能

　・金額、日付、メモ（例：「アクスタ購入」「ライブ当選」など）を入力できるフォーム。

　・「推し（誰のための支出か）」を選択するドロップダウン（例：推しA、推しBと切り替えられるように）。

　・カテゴリ（グッズ、チケット、遠征費、その他）の選択。

3. 履歴一覧

　・登録した支出が新しい順にタイムライン風に並ぶ画面。

　・推しごとに色分けされたタグが付いていると嬉しいです。

4. 推しキャラクター設定

　・自分の「推し」の名前やイメージカラー、写真を登録できる簡単な設定ページ。

まずは、これらの基本機能とデザインを持ったアプリのベースを作成してください。よろしくお願いします！
